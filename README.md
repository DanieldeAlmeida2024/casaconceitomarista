# Casa Conceito Marista

Site estatico com duas versoes de pagina, pronto para deploy na Vercel.

## Paginas

- `v1.html`: versao principal, aberta por padrao em `/`.
- `v2.html`: versao alternativa.

As duas paginas tem um botao flutuante compacto no canto inferior direito para alternar entre as versoes.

## Deploy na Vercel

1. Importe este repositorio na Vercel.
2. Use as configuracoes padrao de projeto estatico.
3. Faca o deploy.

Para rodar localmente com a Vercel CLI:

```bash
npm install
npm run dev
```
